# 📚 Student Planner Pro

A productivity web application designed for students to manage tasks, track progress and improve study habits.

## 🚀 Features

- User Login & Signup
- Personal Dashboard
- Add/Edit/Delete Tasks
- Task Categories
- Priority Management
- Due Dates
- Progress Tracking
- Search Tasks
- Dark Mode
- AI Study Assistant
- Productivity Analytics

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
